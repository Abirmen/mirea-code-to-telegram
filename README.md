# Код из Mail.ru в Telegram 
### (Сделано для СДО МИРЭА)

## Как это работает
Mail.ru
→
IMAP
→
Python
→
поиск 6-значного кода
→
Telegram Bot API
→
Telegram

## Настройка

Создать файл config.py рядом с main.py:

BOT_TOKEN = "TOKEN_БОТА"
CHAT_ID = "ID_ЧАТА"

MAIL_LOGIN = "EMAIL_ОТ_MAIL.RU"
MAIL_PASSWORD = "ПАРОЛЬ_ВНЕШНЕГО_ПРИЛОЖЕНИЯ"

## Mail.ru

**Для подключения через IMAP использовать пароль внешнего приложения, а не основной пароль от аккаунта Mail.ru**

**Параметры подключения:**

**IMAP сервер: imap.mail.ru**

**Порт: 993**

## Запуск
python main.py

После запуска программа будет постоянно проверять почту.

При обнаружении подходящего письма в Telegram придёт сообщение
